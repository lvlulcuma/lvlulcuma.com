title: "Keeping secrets out of code"
summary: "Passwords, API keys and tokens belong in a vault such as HashiCorp Vault, Azure Key Vault or AWS Secrets Manager, not in code, scripts or chat: short-lived credentials, automatic rotation, scanning repositories with gitleaks or GitHub push protection, and revoking a leaked key at once. GitGuardian found 23.8 million secrets in public GitHub commits in 2024, and 70% of those leaked in 2022 still worked."
