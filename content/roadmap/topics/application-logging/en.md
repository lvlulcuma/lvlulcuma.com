title: "Logging in applications"
summary: "Writing the logs that let someone investigate later: sign-ins and failures, access denials, admin actions and input validation errors, with time, user and request ID in a structured format, sent to a central system. Never log passwords, tokens or full card numbers, and neutralize user input so attackers can't forge entries (log injection, CWE-117)."
