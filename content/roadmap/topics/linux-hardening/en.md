title: "Hardening Linux servers"
summary: "Making Linux servers hard to break into: SSH with keys only and no direct root login, narrow sudo rules, unneeded services removed, a host firewall (nftables, firewalld or ufw), SELinux or AppArmor left enforcing, automatic security updates, and CIS Benchmark checks with OpenSCAP or Lynis. Patching SSH matters: regreSSHion (2024) let attackers run code as root on unpatched servers."
